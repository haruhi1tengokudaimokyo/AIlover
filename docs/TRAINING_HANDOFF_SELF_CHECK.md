日期：2026-10-22。检查范围为当前项目后端、前端构建，以及绯华/菖蒲/麦的文本和语音交接链路。

## 发现并修复的问题

1. 麦的 LLM 转换器遇到非字典记录、非字符串 ID 或 `context_zh` 中的非字典项会抛异常，造成整批中止。
   现在按拒绝原因跳过异常记录，并补充对应回归。
2. `seed_ousama` 在查找作者之前创建默认系统提示词，指定不存在的账号失败后会留下修改。
   初始化操作现在在数据库事务中执行，失败回滚；新增不存在作者的回归验证。
3. 旧全局文本目录的译稿有 40 条 mock；旧 `sharegpt.json` 和 seed 文件实际为 JSONL，不能直接当作标准 JSON 数组交接。
   不覆盖历史文件；新交接包从角色卡生成标准 JSON 数组的中文改写 seed，排除 mock，空语料不注册。
4. 绯华旧标注 1784 行、1780 个唯一音频路径，重复项是同音频同文本，不是冲突文本。
   交接副本去重，若未来出现同音频不同文本，则全部排除并记录原因，避免任意选择一条。
5. 原两位的旧参考只按音量排序，会选到喘息或其他不适合日常声线的片段。
   交接副本从开场日常对白重选三组完整参考，检查文本对应、时长、格式、RMS 和峰值；没有声称逐条人工试听。
6. 旧训练路径是 `DATASET_ROOT` 占位符，新包保留相对路径标注，并提供在最终训练机器生成绝对 `train.list` 的工具。
7. 新独立转换/续跑工具只跳过结构与来源校验合格的译稿，拒绝 mock、错误来源、日文残留与未来上下文；
   对中断留下的损坏 JSON 尾行记入报告，不让其阻止续跑，也不把损坏尾行和新记录连在一起。
