# 本机快速启动

双击 `D:\AIlover\AIlover启动.exe`，自动启动当前项目后端并打开桌面界面；桌面窗口不可用时沿用原启动器的浏览器回退。初始化完成前请稍等，不要重复双击。

这是当前项目的快捷启动 EXE，依赖同目录 `.venv`、`launcher.py` 和 `backend`，不能单独移到其它文件夹。需要桌面入口时可为它建立快捷方式。它不把 Key、数据库、游戏素材或训练权重打进 EXE，使用现有后端账号、历史、媒体和百炼四角色配置。

关闭正常桌面窗口后本地后端随之退出；若进入浏览器回退，后台进程继续工作。已有进程运行时再次双击会提示查看原窗口，不会重复启动另一份。浏览器回退退出后需要停止本地进程时，使用任务管理器关闭 AIlover启动 对应进程及其子进程。

启动日志：`D:\AIlover\runtime\desktop\`，`latest-log.txt` 指向本次日志。当前训练语音尚未云端部署，四角色为文本模式。
