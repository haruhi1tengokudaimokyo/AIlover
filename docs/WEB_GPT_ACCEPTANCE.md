## 这轮模型状态

调整的是提示词、上下文、检索、记忆、流式编排和provider接口；没有提供“我们调过的”模型权重。可以先用现有兼容文本/云语音服务开始联调，之后按实验结果调整提示/检索/参数。角色风格质量仍需真实回复与人工审核，声音效果仍需可用音色和试听。
